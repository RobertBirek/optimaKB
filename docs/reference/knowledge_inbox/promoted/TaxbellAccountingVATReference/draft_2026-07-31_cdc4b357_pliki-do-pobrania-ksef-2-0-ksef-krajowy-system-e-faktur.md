Summary:
This page on podatki.gov.pl provides downloadable resources for KSeF 2.0 (Krajowy System e-Faktur). It includes:
- KSeF 2.0 manuals (Parts I–IV) covering getting started, creating/receiving invoices, additional features, KSeF in JST/GV and other access models, and guidance for NGOs.
- Documents section with sample files for the e-invoice structure FA(3) in a ZIP, plus JPK_VAT with declaration case studies showing usage of JPK_VAT with declaration markers.
- Tax explanations (Objaśnienia podatkowe) from 28 Jan 2026 on determining permanent establishment for VAT purposes when issuing invoices using KSeF.
- Informational brochure about the FA(3) logical structure (and an English title/version).
- “Środy z KSeF” downloads: slides (PDF) and YouTube videos from the Ministry of Finance Whatsit sessions.
